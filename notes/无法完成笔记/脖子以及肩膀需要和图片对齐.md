## 结论

**先不管肩膀。** 不影响脸的 fitting。肩颈歪是 HEAD 头模的已知上限，不是 68 点没 fit 好。

FLAME / VHAP 同样没有从根上解决：只有一个脖子关节，下段脖子相对躯干动不了；文档把大动作时难同时对齐下段脖子和头写成模型限制。GNM V3 目前只有 `HEAD`，关节仍是 `neck / head / left_eye / right_eye`，没有锁骨、肩。

---

## 和「有 neck / boundary mask」的区别

UV 里有 `neck`、`boundary`；几何上还有下沿 `bottom`（注释里的 shoulder cut）。这些只是**分区标签**：哪些点进光度、哪些钉住、哪些不做纹理对齐。

- Mask ≠ 肩关节，也不提供「绕锁骨转」的蒙皮自由度。
- 当前光度流程里，脖子 / 裁边还常被**排除或钉住**，避免裁边被拽到画面边缘——是在回避，不是在对齐肩膀。
- 若放开这些点做 `static_offset` 或轮廓项，只能朝照片**挤一点表面**，小错位或许能蹭；大倾斜、真肩线仍对不齐，还容易把脖子拧烂。

## 还能动的 vs 动不了的

| 能（形状） | 不能（关节） |
|---|---|
| 身份 `id_head` 改变脖子粗细、长短 | 头相对肩膀的朝向 |
| `static_offset` 局部鼓/收 | 耸肩、锁骨、肩线倾斜 |
| | 下段脖子相对躯干独立转动 |

粗细长短 ≠ 肩膀对齐。
