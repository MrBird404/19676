# 耳朵高度朝向无监督

状态：等待处理。阶段：二层 all（FLAME / GNM 八格都偏）；细收主要在 offset。

对照：`GNM v4 SAM眼 光度一二层 all 八格.jpg`——两模型耳高、耳朝向相对照片都不对。

## 原因

- 68 点 **几乎无耳点**，landmark 管不到耳尖/耳垂。  
- 单目侧耳常被发/帽遮，光度信号差。  
- 帽边强对比还会把耳廓往外拖（见 `帽边拉头型与耳廓外扩.md`）。  
- VHAP 对 ears **放松 offset 正则**，耳更容易乱飘；GNM offset 笔记里也还缺 `reg_offset_rigid`（VHAP 含左右耳）。

## 可做（按性价比）

1. **all 阶段不硬拧耳**；眼关节式「先注视再冻」不适用于耳。  
2. offset 阶段：对耳加 **刚体式正则**（对齐 VHAP `reg_offset_rigid_for` 含 left/right_ear），防耳壳撕烂。  
3. 系统性耳高偏差：在 lmk/shape 用少量手标耳尖/耳垂（或相关身份维），再冻进光度。  
4. 帽–耳接触带降权 / except，避免耳贴在帽沿上。  
5. GNM 与 FLAME 耳拓扑不同，不要求朝向完全一致；以照片耳垂/耳尖投影为准。

## 要做

offset 对齐时补耳刚体正则；评估是否加稀疏耳监督；与帽边降权一起做。
