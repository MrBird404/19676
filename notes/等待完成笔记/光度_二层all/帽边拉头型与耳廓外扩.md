# 帽边拉头型与耳廓外扩

状态：等待处理（现象已确认，非实现漏抄）。阶段：二层 `rgb_init_all`（一层 tex 已有苗头；offset 上 hair/ears 正则还更松）。

对照：`notes/gnm_uv/测试用图片/GNM v4 SAM眼 光度一二层 all 八格.jpg`（FLAME / GNM 头顶变高、耳贴蓝帽外沿）。

## 现象

- 光度二层后 **无头发的头型仍往上跑**，头顶变高。  
- **耳朵沿蓝色手术帽边缘外扩**，不像真实耳廓位置。

## 原因

蓝帽相对肤色对比强，光度用网格轮廓去「盖住」帽边以减 RGB 误差——是在用脸模解释非脸区域。

| 机制 | 作用 |
|---|---|
| `align_texture_except` 含 **hair** | 帽区 UV detach，但 **RGB 仍进损失**；shape / 后续 offset 仍会被帽边拉 |
| offset 对 hair、ears **放松正则**（VHAP） | 耳廓更容易跟着帽沿鼓出去 |
| 无真实头发几何 | 只能抬头皮网格去罩蓝帽投影 → 头顶变高 |

一层已对齐 hair except（见 `已完成笔记/光度_一层纹理/头发留在纹理对齐里.md`）；本篇记的是 **几何被帽色绑架**，不是 except 开关写错。

## 要做

- 帽/耳接触带：降权或扩 except，避免「耳长在帽沿上」。  
- 头顶：接受 all 阶段有限；真要收轮廓主要靠 **offset**，并评估是否对 scalp/hair 收紧 offset 放松。  
- 对照八格时区分「罩住了」vs「头型对了」。
