## 模型边界（先说死）

- GNM HEAD / FLAME 都是 **颈根单关节** + 身份 +（后面）顶点偏移；**没有**锁骨/肩关节。  
- 真肩线、耸肩对齐仍属 `无法完成笔记/脖子以及肩膀需要和图片对齐.md` 的上限。  
- 本篇前置只求：**头–肩相对角大致对**；长短/粗细交给后面一层 shape 与 offset，不在光度前硬拉长。

## 误区

| 误区 | 纠正 |
|---|---|
| 多拧脖子关节就能贴肩带 | 单关节只改朝向，贴不出锁骨外形 |
| 二层蓝罩「罩住」= 几何齐了 | all 还没开 offset；颜色糊平 ≠ 肩颈对齐 |
| 光度前再 1 维拉长脖子就能齐高度 | **已试，取消**：mean y 能贴上，但颈肩外形变糟；高度留给一层/offset |
| 前置用自由颈顶点 / 整份 id 乱拧 | 易重演表情裸开时的乱 |
| 直接拧 `rot_neck`（根）会动头 | GNM 里 `rot_neck`=根刚体、`rot_head`=头相对颈；**头已定死时不能只拧根** |

VHAP 贴颈肩实际靠：`shape` 粗细长短 + neck 根旋转角度 + **第三层 static_offset** 糊皮面。GNM：光度前 **只钉角**，长短/皮面进一层与 offset。

#### mesh 肩线（与照片对称；已修「只剩脖子 / 横边溢出」）

1. UV **`neck | boundary`** 上色，当前姿态渲染 → 2D mask

3. 底边：mask **左右最宽** WL/WR 连线，以下丢掉；再剥掉贴着 WL—WR 的切口像素  
4. 区间内每行最左/最右 → 左右外轮廓；**走到最外点即停**（勿沿底边切口往回拐）  
5. 每条线只保留 **绿→橙**；`max|dx|` 应很小

#### 自由度（头固定的逆向）

- 正向：肩颈不动，拧头相对颈（`rot_head`）→ 头动。  
- **逆向（本步）**：拧 `rot_head`（主 pitch，轻 roll；jaw y 近锚），再用 **根 `rot_neck` + translation 闭式补偿**，把 **头关节世界变换钉回初值** → 头几乎不动，肩颈相对图在动。  
- 脸投影 MSE 作验收。  
- **不要**只优化 `rot_neck`：那是整头刚体，会把已定好的头拧飞。
