# 下轮廓射线外沿约束

状态：已完成（定稿试跑）。阶段：`rgb_init_texture` → `rgb_init_all`（`--w_jaw_outer` / `--jaw_outer_slack`）。

动机：二层脸颊偏方、轮廓吃背景/蓝帽；外沿单边能挡外溢，但挡不住二层 RGB 把下颌往里收。**不用**点对点 jaw lmk（`jaw` 权重仍为 0）；用检测点当可见脸外轮廓的 **射线半径** 目标。

## 定稿做法

- 中心：鼻尖 `gt[30]`；射线：中心 → `gt[i]`；监督点 **只要 3–13**（近耳 0–2 / 14–16 会收过头）。
- 一层：可先外沿单边；二层：**双边** `relu(|mesh_r − gt_r| − slack)²`（±slack 死区），不是顶点↔点对应。
- 二层 **不** 把脸 `boundary` 从 AA 里摘掉（那是关梯度，不是减弱）；轮廓靠加大双边权重压住。
- 权重：一层常用 `w_jaw_outer=20`；二层定稿 **`w_jaw_outer=40`**，`jaw_outer_slack=2` px。
