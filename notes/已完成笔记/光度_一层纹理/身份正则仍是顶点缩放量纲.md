# 身份正则仍是顶点缩放量纲

状态：已完成。`photo_fit.py` 一层身份正则已改成对系数做 `mean(coef²)`，与 landmark 侧、VHAP `reg_shape` 同量纲。

同类 landmark：`已完成笔记/身份正则不是同一套量.md`。

## 原因（旧）

`metric_reg` 曾用 `reg_id * mean((id_scale @ identity)²)`。同写 0.3 比系数正则松约三个数量级；一层 shape 与贴图同开时头型易被 RGB 拉开，UV 对错像素。

## 改法

- `mean(id_head ∥ id_eyes 系数²)`，`reg_id=0.3`
- `id_eyes` 也 `clamp±5`
- 一层不开表情；关节正则不再拉 `rot_neck`（留给二层）

## 结果

| | `id_head` L2 | `id_eyes` L2 |
|---|---:|---:|
| 新 lmk（sam_eyes） | 1.66 | 0 |
| 旧 `photo_l1*`（顶点量纲） | ~13 | ~12 |
| 新一层（系数正则） | ~6 | ~1 |

比旧光度收得住；一层 RGB 仍会略动 shape，属 VHAP 一层也开 shape 的正常现象。六格见烤帽 / 残差 / 2048 各版测试图。
