# 关节正则用轴角而不是旋转矩阵

状态：已完成（确认可忽略，未改代码）。

对照图：`notes/gnm_uv/测试用图片/GNM v4 + PCA150 根旋转不拉0 身份正则类似.jpg` 第 0 帧。

## 差别是什么

VHAP `compute_joint_L2_energy`：把关节轴角变成旋转矩阵，对零姿态做 `mean((R₀ − R)²)`。

GNM `vhap_monocular` 的 `metric_reg`：直接 `mean(aa²)`。

下巴负向张开、`y/z` 惩罚、左右眼差，两边结构已经对齐；根旋转也不再往 0 拉。只剩主项用轴角还是旋转矩阵。

## 为什么几乎没影响

单目跟脸时，下颌 / 眼 / 解剖脖子多在几度到十几度。这一档里 `mean(aa²)` 和 `mean((R₀−R)²)` 几乎成固定约 **1.5 倍**，等于权重刻度差一点，不是另一种先验。要到大约 45° 以上比例才明显拉开，当前拟合走不到。

本帧下颌、眼关节本来就很小（眼常近 0），八格图上看不出这项。

## 交付结论

不改代码。保持轴角平方即可；真要数值上咬死 VHAP 再换成旋转矩阵差，对现在的点对齐结果没有实质必要。
