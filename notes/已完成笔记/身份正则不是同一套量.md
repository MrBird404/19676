# 身份正则不是同一套量

状态：已完成。`vhap_monocular` 身份正则改为对系数做 `mean(id²)`，对齐 VHAP 的 `reg_shape` 量纲。

对照图：
- 仅根旋转自由：`notes/gnm_uv/测试用图片/GNM v4 + PCA150 根旋转不拉0.jpg`
- 再加身份系数正则：`notes/gnm_uv/测试用图片/GNM v4 + PCA150 根旋转不拉0 身份正则类似.jpg`

## 原因

VHAP：`0.3 * mean(shape²)`，300 维系数，`std_shape=1`。

GNM 原先：`0.3 * mean((id_scale @ identity)²)`。`id_scale` 来自 `scaling_for_identity_loss`，量纲是顶点位移。同写 0.3，实际先验大约松三个数量级，头型更容易被 68 点拉开。

## 改法

`19676/GNM_Fit/fit_gnm.py`：`vhap_monocular` 下对可优化的 `id_head + id_eyes` 做 `reg_id * mean(coef²)`。牙齿维保持 0，不进均值。其它 preset 仍用原来的 `id_scale` 路径。

## 结果（第 0 帧，PCA150，v4，根旋转自由）

| | 身份 L2 | 整体误差 |
|---|---:|---:|
| 旧顶点缩放正则 | 6.53 | 1.53 px |
| 系数正则（VHAP 量纲） | **1.66** | 1.86 px |

头型明显收住（接近 VHAP shape L2≈2.8 这一档），点误差略升，符合「少靠改头型硬凑点」。输出：`gnm_fit_out/expression_v3/lmk_align_vhap_frame0_v4_exppca150_idcoef`。
